# Politique de sécurité

## Versions supportées

| Version | Supportée |
|---------|-----------|
| 1.0.x   | ✅        |
| < 1.0   | ❌        |

## Nature du projet

DarkMonopoly est un **jeu hors-ligne** :
- aucune connexion réseau,
- aucun stockage de données personnelles,
- aucun envoi de télémétrie.

Les risques de sécurité sont donc **très limités**.

## Signaler une vulnérabilité

Si tu identifies malgré tout un problème (par exemple une exécution de code non voulue via un fichier de sauvegarde),  
ouvre une **issue privée** via l'onglet *Security → Report a vulnerability* de GitHub, ou contacte directement le mainteneur.

Merci de **ne pas** divulguer publiquement une faille avant qu'elle ne soit corrigée.
